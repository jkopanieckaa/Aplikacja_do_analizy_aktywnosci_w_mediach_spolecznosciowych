# Aplikacja_do_analizy_aktywnosci_w_mediach_spolecznosciowych
Application for analyzing social media activity

Projekt inżynierski zrealizowany w ramach pracy dyplomowej na Zachodniopomorskim Uniwersytecie Technologicznym w Szczecinie.

W katalogu projektu uruchom w terminalu polecenie: streamlit run Strona_Główna.py
Aplikacja powinna otworzyć się w przeglądarce internetowej

Do uruchomienia aplikacji potrzebna jest wcześniej zainstalowana biblioteka streamlit: pip install streamlit
